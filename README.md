# PL Studio Adventure Tabs

🔴 **GEODE BUTTON IS NOW IN SETTINGS!!!**

Geode mod for Geometry Dash 2.2081.

- Activates the original `THE MAP` button and replaces its announcement popup.
- Restores a scrollable fan reconstruction of The Map.
- Keeps the original `VERSUS` button as a safe inactive placeholder.
- Supports Windows and Android through one `.geode` package.
