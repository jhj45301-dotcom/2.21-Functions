# 2.21 Functions

<cr>GEODE BUTTON IS NOW IN SETTINGS!!!</c>

2.21 Functions is a fan-made Geode mod by **PL Studio** for legally owned
copies of Geometry Dash 2.2081.

It restores the coloured **The Map** entry, its Keymaster dialogue, a
scrollable map view with the player's selected icon, and an intentionally
inactive **Versus** placeholder. No black screen or popup is opened by the
Versus button. The mod supports Windows and Android.

This project is unofficial and is not affiliated with RobTop Games or the
Geode team.
